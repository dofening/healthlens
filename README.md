# 健康透镜 HealthLens

在 Windows 上离线查看 iPhone「健康」App 导出的数据。支持来自 Apple Watch 和 AirPods 等设备的记录，可查看活动、心率、睡眠、训练路线、听力和心电图，并按时间范围筛选。

## 快速开始

1. 从仓库的 **Code → Download ZIP** 下载并解压项目。
2. 双击 [健康透镜.cmd](./健康透镜.cmd)。程序会在 Microsoft Edge 中打开，无需安装项目依赖或构建。也可双击「创建桌面快捷方式.cmd」添加启动入口。
3. 在 iPhone 的「健康」App 中点右上角头像，选择「导出所有健康数据」。把生成的 ZIP 传到电脑，拖入程序窗口即可导入。

更多功能和统计口径见 [使用说明](./使用说明.txt)。

## 数据隐私

应用在本机解析导出文件，解析结果保存在浏览器的 IndexedDB 中。使用 Windows 启动器打开时，Edge 配置和解析结果位于项目目录的 `data/edge-profile`。可在「设置 → 清除本机保存的数据」中清理。请勿把个人健康导出文件或该配置目录提交到 GitHub。

图表和统计分析仅供个人参考，不能用于医学诊断。
